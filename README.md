# Credit-card-fraud-detection

The proposed solution integrates Genetic Algorithms (GA) for feature selection and Random Forest (RF) for classification. Genetic Algorithms are used to identify the most relevant features from large transaction datasets, reducing computational complexity while improving accuracy. Once the key features are selected, the Random Forest classifier is applied, which is well-suited to handle the classification of imbalanced datasets where fraudulent transactions represent a small percentage of the total.
The dataset used in this project consists of real-world credit card transaction data. Key preprocessing steps include handling missing values, normalizing features, and applying oversampling techniques like SMOTE to balance the dataset. By optimizing feature selection and leveraging the robustness of ensemble learning, the system minimizes false positives while maintaining high detection accuracy.
The project was evaluated using several performance metrics, including accuracy, precision, recall, F1-score, and AUC-ROC. The model achieved high accuracy with low false-positive rates, demonstrating the effectiveness of combining GA and RF in detecting credit card fraud. The final system is capable of real-time fraud detection, providing a scalable solution for financial institutions to protect their customer.
